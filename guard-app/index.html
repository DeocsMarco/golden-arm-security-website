Golden Arm Guard App

Install the Golden Arm app on your Android phone to stay connected with your team, get real-time updates, and manage your shifts on the go.

Download App Android APK

APK signature and installation have not been independently verified.

How to install

  1. Download

    Tap Download App to save the file to your Android phone.

  2. Open the file

    Open it from your notification panel, or from your Downloads folder.

  3. Allow the install

    If prompted, allow installation from the specific trusted browser or file source you used to download the app. Never disable Play Protect.

    After installation, turn off that source’s permission to install unknown apps.

  4. Install

    Tap Install and wait for it to finish.

  5. Sign in

    Open the app and sign in. Need access? Contact your administrator.

Already have access?

Sign-in is separate from the Android download. Need access? Contact your administrator.
